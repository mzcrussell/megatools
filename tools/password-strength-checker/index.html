What Makes a Password Strong?

A strong password should be long, unique and difficult to predict. Length is particularly important, but predictable phrases and repeated patterns can still make long passwords vulnerable.

Understanding Password Entropy

Password entropy is an estimate of how difficult a password may be to guess. A simplified calculation considers password length and the number of possible characters.

However, entropy estimates based only on character variety can overestimate the security of predictable passwords, dictionary words and common substitutions.

A strength score is not a guarantee that your password is secure or has never appeared in a data breach.

Best Practices for Password Security

  • Prefer passwords of at least 15 characters when possible.
  • Use a different password for every account.
  • Avoid names, birthdays and predictable sequences.
  • Use a trusted password manager to generate and store passwords.
  • Enable multi-factor authentication or passkeys where available.
  • Change passwords if they are exposed or compromised.
  • Never share passwords through email or public messages.
